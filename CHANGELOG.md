# Changelog

## 1.0.0 (unreleased)

First public release. The release date is set when the tag is created.

- The skill in English, Portuguese and Spanish, with the same rules in all three.
- Step 0: the person's adjustments (add, release, swap alternatives). The skill also looks for them in AGENTS.md and other instruction files, not only in CLAUDE.md.
- Step 1: identity before layout, with a worked example, a rule for when no other projects are in view and a rule for when the person already has a brand.
- Habits that give AI work away, each with a reason and an alternative. Slashes, dashes and italic serif are in a separate section, as the author's own pet peeves.
- Approval and fidelity rules apply only when an approved design, brief or existing design is present.
- An "Other formats" table that says how each website rule reads in posters, slides, social posts, banners and covers.
- A final review with a logo test and a neighbor test.
- READMEs in three languages, with a version badge, notes for other AI tools and one ready zip per language for the release page.
